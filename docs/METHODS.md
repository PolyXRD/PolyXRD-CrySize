# 计算方法体系：5 组 7 种与选择场景

PolyXRD CrySize v2.0.0 把晶粒尺寸/微应变的计算方法从「谢乐 + Williamson-Hall」
扩展为 **5 组、细分 7 种**。本文说明每种方法的物理假设、输入要求、适用
场景与局限，以及它们之间的可比性边界。

## 1. 总览

| 组 | 细分方法 | 主输出 | 次级量 | 额外输入要求 |
|---|---|---|---|---|
| ① 谢乐法 Scherrer | 1. FWHM 口径（K=0.89）<br>2. 积分宽度口径（K=1.0） | 数目平均 D | — | 标样（可选，推荐） |
| ② W-H 均匀形变 UDM | 3. UDM | D + ε | ε (%) | 标样（强烈推荐） |
| ③ W-H 均匀应力 USDM | 4. USDM | D + σ | σ (MPa) | 标样 + 晶格参数 a、弹性常数 c₁₁/c₁₂/c₄₄ |
| ④ W-H 形变能密度 UDEDM | 5. UDEDM | D + u | u (MJ·m⁻³) | 同 ③ |
| ⑤ Warren-Averbach | 6. 单峰近似（Voigt 单线法）<br>7. 多级反射傅里叶法 | D（体积加权） | ⟨ε²⟩^½ | 6：标样<br>7：标样 + ≥3 峰且 d 值 ≥2 种 |

合计 **5 组 / 7 种**。此外「**按晶向分组**」是 ②③④ 共用的增强开关，
不是独立方法（见 §3）。

## 2. 逐方法说明

### ① 谢乐法 Scherrer（2 种）

    D = K·λ / (β·cosθ)

| 细分 | 宽度口径 | K | 仪器宽化扣除 |
|---|---|---|---|
| FWHM 口径 | FWHM | 0.89 | β = √(FWHM_obs² − FWHM_inst²) |
| 积分宽度口径 | 积分宽度 | 1.0 | β = β_obs − β_inst |

- **假设**：全部宽化来自有限晶粒尺寸；不含应变、层错、位错贡献。
- **两种口径的区别**：积分宽度在卷积下严格可加和（Stokes, *Proc. Phys.
  Soc. A* **61** (1948) 382），FWHM 不可加和（仅在各分量近似高斯时才可
  用平方差）。峰形越接近洛伦兹（η 大），积分宽度口径越稳。
- **适用场景**：只求一个尺寸量级、不需要分离尺寸与应变的常规筛查；也用
  作其它方法的量级参照。
- **局限**：微应变被算进尺寸，D 系统性偏小；D > 100 nm 时 β 由两个相近宽
  度相减得到，相对不确定度急剧放大，失去定量意义。

### ② UDM（均匀形变模型）

    β·cosθ = Kλ/D + 4ε·sinθ        横轴 X = 4sinθ，斜率 = ε，截距 = Kλ/D

- **假设**：微应变在各方向相同（各向同性均匀形变）—— Williamson & Hall,
  *Acta Metall.* **1** (1953) 22 的经典形式。
- **输入**：≥ 2 个有效峰；强烈建议配标样，否则仪器宽化被算作尺寸。
- **适用**：要把 D 与 ε 分开的标准情形，三种变体中输入最少。
- **局限**：各向异性样品线性度差，D 与 ε 相互污染。

### ③ USDM（均匀应力模型）

    β·cosθ = Kλ/D + 4σ·sinθ/E(hkl)    横轴 X = 4sinθ/E(hkl)，斜率 = σ
    逐峰应变 ε(hkl) = σ / E(hkl)

- **假设**：应力 σ 各方向相同，应变按各晶向刚度分配。W-H 原文已讨论此情
  形；现代表述见 Noyan & Cohen, *Residual Stress: Measurement by
  Diffraction and Interpretation*, Springer (1987)。
- **输入**：立方晶格参数 a 与弹性常数 c₁₁/c₁₂/c₄₄，用于指标化与 E(hkl)。
- **适用**：弹性各向异性明显、残余应力型宽化主导时；与 UDM/UDEDM 比 R² 选优。
- **局限**：依赖 E(hkl) 准确度；a 值或点阵类型填错会污染全部横轴，且不会
  报错——**指标化结果必须在界面上核对**。

### ④ UDEDM（均匀形变能密度模型）

    β·cosθ = Kλ/D + 4sinθ·√(2u/E(hkl))   横轴 X = 4sinθ·√(2/E(hkl))，斜率 = √u
    逐峰应变 ε(hkl) = √(2u/E(hkl))

- **假设**：形变能密度 u = ε²E/2 各方向相同。纳米粉体峰宽分析常用，见
  Bindu & Thomas, *J. Theor. Appl. Phys.* **8** (2014) 123。
- **输入**：同 ③。
- **适用**：形变由位错、界面能主导的纳米粉体，实践中往往比 USDM 线性更好。
- **局限**：同 ③；能量均匀假设对致密块体未必成立。

### 三变体实测对比（CeO 样品 + Si 标样，同一组峰拟合）

| 变体 | D (nm) | 次级量 | R² |
|---|---|---|---|
| UDM | 17.70 | ε = 1.129 % | 0.795 |
| USDM | 13.69 | σ = 2058 MPa | 0.920 |
| UDEDM | 17.88 | u = 14.22 MJ·m⁻³ | **0.983** |

同一组数据上 UDEDM 的线性度显著优于 UDM，说明该样品的宽化更接近「形变能
密度均匀」而非「应变均匀」。这正是三变体并列的意义：**用 R² 与残差结构
反推哪种物理假设更贴合样品**，而不是默认相信某一个。

### ⑤ Warren-Averbach（2 种）

傅里叶空间分离尺寸项与应变项：

    A(L) = A^S(L) · A^D(L)，A^D(L) = exp(−2π²L²⟨ε_L²⟩/d²)
    对固定 L，ln A(L) 对 1/d² 回归：截距 → ln A^S(L)，斜率 → −2π²L²⟨ε_L²⟩
    A^S(L) ≈ 1 − L/D_v（小 L）→ D_v = −1/(d lnA^S/dL)

依据：Warren & Averbach, *J. Appl. Phys.* **21** (1950) 595；
Warren, *X-ray Diffraction*, Addison-Wesley (1969)。

**6. 单峰近似（Voigt 单线法）**：把伪 Voigt 的洛伦兹分量归尺寸、高斯分量
归应变——

    β_L = η·(π/2)·FWHM      →  D = Kλ/(β_L·cosθ)
    β_G = (1−η)·√(π/4ln2)·FWHM →  ε = β_G/(4 tanθ)

依据：de Keijser, Langford, Mittemeijer & Vogels, *J. Appl. Cryst.* **15**
(1982) 308；Langford et al., *Aust. J. Phys.* **41** (1988) 173。
优点是不要求测到多级反射；缺点是**强依赖线型假设**，真实线型偏离时 D、ε
偏差可达 20% 以上，**不可与傅里叶法结果混用**。

**7. 多级反射傅里叶法**：真正不做线型叠加假设的方法。要求 ≥3 个有效峰且 d
值至少 2 种（同族多级反射最佳，如 {111}/{222}、{200}/{400}）、必须配标样
做 Stokes 解卷积。输出体积加权尺寸 D_v 与随 L 变化的均方应变。
局限：窗口内邻峰、Kα₂ 残余与噪声都会被傅里叶变换放大；不满足条件时程序
拒算并给出原因。

## 3. 按晶向分组（②③④ 的增强开关）

各向异性样品把所有峰混在一起回归会拉低 R²。分组依据弹性各向异性参数

    Γ = (h²k² + k²l² + l²h²) / (h² + k² + l²)²

Γ 相同则 E(hkl) 相同，组内回归才自洽。立方晶系中 {111}/{222}（Γ=1/3）、
{200}/{400}（Γ=0）、{220}/{440}（Γ=1/4）正好构成可回归的组，**前提是谱里
能测到这些高级次**。

- 开启方式：侧栏「按晶向分组」勾选；需先填晶格参数完成指标化。
- 若所有组都不足 2 个峰（谱里没有高级次），程序自动**退回不分组**并在界
  面/报告注明，不会给出空结果。

## 4. 三条必须知道的边界

1. **无弹性常数时 ②③④ 退化为同一条拟合线**。E(hkl) 取常数时
   σ = ε·E、u = ε²E/2，三个变体只是重参数化，R² 与 D 完全相同，不产生
   新信息。此时界面标注「降级」。
2. **口径不可混用**：谢乐法两种口径的 K 不同；单峰 W-A 与傅里叶 W-A 的
   物理含义不同。跨方法比数值大小没有意义——谢乐给数目平均，傅里叶法给
   体积加权。**应该比较的是同一方法内的一致性**。
3. **无标样时**所有方法都把仪器宽化算进晶粒尺寸，结果只作相对参考，报告
   会在警告区首位提示。

## 5. 选型决策

1. 只要一个尺寸量级 → ①（优先 FWHM 口径；峰形拖尾明显改积分宽度口径）。
2. 要分离尺寸与应变 → ②；无弹性数据时它就是 ③④ 的等价结果。
3. 有可靠弹性常数、各向异性明显 → ③④② 三者都跑，比 R² 选最优；
   若谱里有同族高级次，再开「按晶向分组」。
4. 数据质量好、有多级反射 → ⑦，它是唯一不预设线型叠加的方法。
5. 没有多级反射但仍要尺寸/应变分离 → ⑥，接受线型假设带来的偏差。
